# KT-09 办公日期任务链

候选最小修改：nissu结果下添加公司休日/月CSV到eigyoubi、银行休业到ginkou-eigyoubi的明确分流；不新增工具或URL。原nissu能算默认土日祝、日期差与N营业日，不能把公司额外休假自动套进去。

真实试用场景（手机390、桌面1440）：8/3—8/11，勾两端→9暦日/6营业日→读初日与祝日解释→复制结果；9/18后1营业日→9/24（日本连休）；清空基准日撤旧结果。月度任务选择2026/9→填公司休日9/1→18营业日→下载30个日行+表头CSV、核公司休日标记→复制结果URL→独立接收页恢复18。填2/30→撤结果、禁下载、藏分享。

边界：默认公司周一至五，银行另有12/31—1/3休业；公司周工作日可选但并非自动读取雇主规则。CSV为计算表，非法律期限证明；nissu起算日规则与合同/法律可能不同，正文已有提示。2026/2027办公月表范围维持既有。复制为本机Clipboard API，无社交发送；脚本拦截外部请求。见browser-check.mjs/browser-results.json。完整键盘无鼠标遍历、屏幕阅读器、跨浏览器和所有假日组合未验。
