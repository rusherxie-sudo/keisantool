## 1. 词表到底说明什么

原表 2,100 行；NFKC 和去空白后 1,997 个规范词（减少103条）。988行 Volume=0，1,361行缺少 KD。没有2027关键词，且大量2021—2024年份词，故不能把文件名日期当成全部搜索量的新鲜度。文件无统计窗口说明，Volume按供应商搜索量指标使用，不宣称是2026年11月实测月需求；零不等于绝无需求。

空格变体的Volume常相同、KD却不同。例如「六 星 占 術 自動 計算」33100/KD21与「六星占術 自動計算」33100/KD23是同一任务，不能相加，也不应该分别建页。规范词抽样保留最高Volume的一行（同值保留原顺序首行），原值全部留在keyword-map.csv。

词表含「谷町 六 丁目」「六 所 神社」、其他占卜体系、人物新闻、出版物与官方服务导航。它是关键词研究导出，不是六星占术全部需求的完整清单。细木数子的个人搜索量不能当作免费计算工具的目标容量。KD是第三方估计，不代表本站能达到的排名。

## 2. 六星占术的产品结构

- 运命星：生日对应六种星，结合出生年的阴阳形成12类型。查“何星人”“プラス・マイナス”“自動計算”本质上属于同一入口任务。
- 年运：12阶段周期，阴影、停止、减退合称大杀界；健弱和乱气对应小、中杀界。年度表、过去查询、未来区间都能复用同一经过核验的年运计算。
- 霊合星人：生年在本人类型周期中属于“停止”；仍属于原来的运命星，同时参看对应副星。同极性配对：土星↔天王星、金星↔木星、火星↔水星。
- 相性：两人关系，本站当前是双向地运；页面上的百分比是本站自定义评分，不是官方概率。霊合相性和年运相性不能直接拿现有分数冒充。
- 宿命大杀界：另属大运计算，涉及性别、顺逆、节气起运等。不能以某星人的年运或出生年简单代替。现有工具仍缺最终年龄区间的独立对照，本轮未宣称修复。
- 日运/月运：同名12阶段不代表与年运同一锚点；须分别核验日期起点和月界，再开发。
- 早见表有两种任务：出生年月→运命数/星数→运命星，与12类型→某年运势。目前本站早见表主要覆盖后者，这是需要优先弥补的意图缺口。

年界是关键：本轮新增工具明确采用1月1日暦年方式。部分资料/旧方式采用立春，在年初会有差异，不能笼统说“所有来源结果相同”。

## 4. Hub、链接与防止内耗

主入口 `/rokusei/` → 查表、霊合、相性、12类型页。霊合工具 → 对应主星类型年表、年度表、相性工具。类型页 → 主工具用于反查生日、相关年表。现有教程 → 工具完成任务。

不单独创建“無料”“自動計算無料”“調べ方無料”等同意图页面。拼写变体只自然解释，不堆砌空格或错误写法。年度URL保持稳定，过去年份保留可查询价值；不批量迁移或删除。keyword-map.csv 是每条原词的候选归属，规则分类不是逐词日本SERP验证；高量且混合意图的组须人工/实时复核后才扩内容。
