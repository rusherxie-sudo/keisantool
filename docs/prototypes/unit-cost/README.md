# 日用品单次成本原型（候选，未进入 Astro 路由）

在仓库根目录运行 `python3 -m http.server 4399 --bind 127.0.0.1`，访问 `http://127.0.0.1:4399/docs/prototypes/unit-cost/`。不需要依赖、账号或构建。浏览器原型不得作为站点根目录公开部署。

支持 mL/L、g/kg、个；不同量纲拒绝比较，不推断密度。每个候选可指定独立每次用量；对比单次现金成本、整包付款、给定期间从零库存购买整包的总支出。积分单列，不能抵扣现金；不评估清洁力、浓缩度、送料或有效期。零价有效，容量/用量必须正，零使用频次无用完日数。无统计、持久化、商品库和生产URL。

用完期限仅为实验算术，未证实需求。待目标用户验证：能否理解每次用量并正确从包装取得；单次成本/期间支出何者决定选择；是否需要用完日数；积分分列是否减少误判。未做真人访谈，未获得正式开发/上线批准。
