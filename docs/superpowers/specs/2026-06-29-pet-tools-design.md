## 1. 背景と市场数据

宠物计算工具是 keisantool 尚未覆盖的高潜力品类。两轮独立调研一致确认：年齢換算・ごはん量・妊娠期間 都是**高搜索量・低竞争（KD 9〜17%）・CPC 极低（≈$0.01〜0.30）**的蓝海，且现有竞品多为薄博客或大品牌附属页，新站 3〜6 个月内可排名。

### SEMrush 实测（JP库・月间検索量）

| 工具方向 | 代表词 | 月间量 | KD | CPC |
|----------|--------|--------|-----|-----|
| 犬の年齢換算 | 犬の年齢 人間換算 | **~9,000**（词簇11K） | 17% | $0.01 |
| 猫の年齢換算 | 猫 年齢 人間換算 | **1,900** | 17% | $0.01 |
| 猫のごはん量 | 猫 ご飯 量 | **6,560** | 16% | $0.16 |
| 犬のごはん量 | 犬 ご飯 量 | **3,130** | 10% | $0.20 |
| 猫の妊娠期間 | 猫 妊娠 期間 | **5,400** | 17% | $0.01 |
| 犬のワクチン | 犬 ワクチン スケジュール | **1,300** | 9% | $0.30 |

> 関键发现：① 选词必须贴生活口语 —「ごはん量」(猫6.5K) ≫「食事量計算」(160)。② 猫の妊娠期間 5.4K 是被低估的最大穴场，SERP 第10位仅 AS21 弱小站（neko-home.or.jp）。③ ワクチン量小但 CPC 最高。

### 排除项

- ✗ 犬の適正体重計算（「犬 適正体重 計算」仅 210/月）→ 不单独成页，以 BCS 肥満度判定整合进ごはん量工具。
- ✗ 犬種別体重（「犬種 体重」仅 40/月）→ 不做。

## 5. 各工具详细规格

> ⚠️ 标注「【要确认】」的公式/数值，实现阶段须由 **calc-verifier 子Agent 对照日本权威一次资料**（環境省 / WSAVA Global Nutrition Guidelines / AAHA / iCatCare 等）最终确定，再写入测试。下方给出**初始参考值**，非最终。

### 5.1 `pet-age.js` — 犬猫年齢換算（页面 inu-nenrei / neko-nenrei）

**导出**：`dogHumanAge(years, size)`、`catHumanAge(years)`、`ageTable(kind, size)`（早見表）。

**犬（体型 3 区分）【要确认】**
- 小型・中型犬：1歳=人間15歳、2歳=24歳、3歳以降 `+4歳/年` → `human = 24 + (age-2)*4`（age≥2）
- 大型犬：成熟遅・老化早。1歳=12歳、2歳=22歳、3歳以降 `+7歳/年` 程度（諸説あり、calc-verifier 确认環境省/AAHA 表）
- 体型区分：小型≤10kg / 中型≤25kg / 大型>25kg

**猫【要确认】**
- 1歳=18歳、2歳=24歳、3歳以降 `+4歳/年` → `human = 24 + (age-2)*4`（age≥2）
- 1歳未満は月齢ベース（生後6ヶ月≈10歳 等、iCatCare 表で确认）

**输入**：生年月日（→自动算月齢/年齢，复用 `shussan.js` 的 `toDate`）or 直接年齢；犬は体型选择。
**输出**：人間換算年齢（◯歳◯ヶ月相当）+ 早見表（1〜20歳）。
**测试要点**：各体型边界（10/25kg）、1歳・2歳・10歳・15歳の換算値、月齢 unter 1歳、無効入力 → null。

### 5.2 `pet-food.js` — DER 喂食量（页面 inu-gohan / neko-gohan）

**导出**：`rer(idealWeightKg)`、`der(idealWeightKg, factor)`、`dailyGrams(der, foodKcalPer100g)`、`idealWeight(currentKg, bcs)`、`perMeal(grams, meals)`。

**公式（犬猫共通の枠组み・科学的标准）**
- `RER = 70 × 理想体重(kg)^0.75`
- `DER = RER × 活動係数K`
- `1日量(g) = DER ÷ (フードkcal/100g) × 100`、`Math.floor` 切り捨て（端数处理沿用项目约定）
- `1回量 = floor(1日量 / 食事回数)`

**活動係数 K【要确认・calc-verifier 必須】**（初始参考、WSAVA/MSD で最終确定）

| 状态 | 犬 K | 猫 K |
|------|------|------|
| 避妊去勢済 成体 | 1.6 | 1.2 |
| 未避妊 成体 | 1.8 | 1.4 |
| 減量中 | 1.0 | 0.8 |
| 幼体（離乳〜4ヶ月） | 3.0 | 2.5 |
| 幼体（4ヶ月〜成体） | 2.0 | 2.0 |
| 高齢 | 1.4 | 1.1 |

> 调研中 wepet 的 1.6/1.2 被否（来源不权威），数值方向可参考但须以 WSAVA/AAHA 一次资料定稿。

**理想体重（BCS 補正）【要确认】**：采用日本常见 **5 段階**（環境省/keisan.site 准拠）。BCS3=理想。`理想体重 = 現体重 ÷ 補正係数`，补正系数初始：BCS1=0.85 / BCS2=0.92 / BCS3=1.0 / BCS4=1.15 / BCS5=1.30。BCS 用图示+説明选择（无体重场地的纯选择输入）。

**输入**：現体重・ライフステージ(活動係数)・BCS(5段階・图选)・フードkcal/100g・1日食事回数。
**输出**：1日のごはん量(g) + 1回あたり(g) + 理想体重 + 過体重/痩せ的提示。
**测试要点**：RER 幂运算精度、各係数档、BCS 逆算理想体重、kcal 边界、切り捨て验证、無効入力。

### 5.3 `pet-pregnancy.js` — 妊娠期間（页面 neko-ninshin / inu-ninshin）

**导出**：`dueDate(matingDate, kind)`、`dueRange(matingDate, kind)`、`elapsed(matingDate, today)`（現在◯日目/週目）、`weeklyStages(kind)`（週ごとの発育目安）。复用 `shussan.js` 的 `toDate/toISO/addDays`（UTC正午基准）。

**天数【要确认】**
- 猫：平均 65日（範囲 58〜67日）→ 出産予定 = 交配日+65、範囲 +58〜+67
- 犬：平均 63日（範囲 58〜68日）→ 交配日+63

**输入**：交配日（必须）。**输出**：出産予定日 + 出産可能範囲 + 現在妊娠◯日目/第◯週 + 週ごとの母体・胎児の変化目安。
**测试要点**：天数加算正确、範囲上下限、交配日未来 → null、跨年/闰年（UTC基准已保证）、kind 参数化。

### 5.4 `pet-vaccine.js` — ワクチン接種目安（页面 inu-vaccine / neko-vaccine）

**合规形态**：定位「接種時期の**目安カレンダー**」= 本质日期排版工具，**不诊断、不推荐具体疫苗品牌/剂量**。

**导出**：`puppySchedule(birthDate, kind)`（子犬/子猫の初年度目安）、`adultReminder(birthDate, today, kind)`（成体の追加接種目安）。

**スケジュール（目安）【要确认】**
- 子犬/子猫の混合ワクチン：初回 生後 6〜8週、以降 3〜4週ごと、最終 16週以降。计 2〜3 回。
- 1歳：追加接種。成体以降：年1回 ／ WSAVA はコア3年ごと（**両論併記・断定しない**）。
- 犬の狂犬病ワクチン：**狂犬病予防法で法的義務**（生後91日以降に1回 + 以降年1回・毎年度）→ 明记（法令ベースで安全かつ有用）。

**输出**：生年月日から各接種の目安日カレンダー + 両論併記 + 强免責。
**测试要点**：生後週数→接種日算出、最終接種の16週条件、狂犬病の91日条件、kind 分歧。

6. **ワクチン目安**：子犬/子猫の初回週齢・回数、狂犬病予防法の 91日/年次義務（厚労省/農水省）。
