## 消費者金融の利息とは

消費者金融（クレジットカードローン・キャッシング）の利息は、借入金額に対して支払う利息です。消費者金融の利息は、プロモーション期間の低金利と通常の高金利があります。

## 利息の計算方法

### 単利計算

消費者金融の利息は基本的に単利で計算されます。

```
利息 = 借入金額 × 年利率 × 借入期間（年）
```

例：10万円を年利率15%で1年間借入した場合

```
利息 = 100,000 × 15% × 1 = 15,000円
```

### 日割り計算

短期間の借入の場合は日割りで計算されます。

```
利息 = 借入金額 × 年利率 ÷ 365 × 借入日数
```

例：10万円を年利率15%で30日間借入した場合

```
利息 = 100,000 × 15% ÷ 365 × 30 ≈ 1,232円
```

## プロモーション金利と通常金利

### プロモーション金利

新規契約時や一定期間限定で適用される低金利です。

- 0%金利キャンペーン
- 低金利期間（例：6ヶ月間2.9%）

### 通常金利

プロモーション期間終了後に適用される通常の金利です。

- クレジットカードローン：年15%〜18%程度
- キャッシング：年18%程度

## 消費者金融の注意点

### 利息の上限

利息制限法により、利息の上限が定められています。

- 借入金額100万円未満：年20%
- 借入金額100万円以上：年15%

### 遅延損害金

返済が遅れた場合、遅延損害金が発生します。

- 年14.6%程度が一般的

### 複利の危険性

最低返済額だけを支払っていると、利息が積み重なって残高が減りにくくなります。これを「複利の罠」と呼びます。

### 借入の際の確認事項

1. 年利率はいくらか
2. プロモーション期間はいつまでか
3. 遅延損害金はいくらか
4. 繰り上げ返済は可能か
5. 手数料はかかるか

## まとめ

消費者金融の利息は単利で計算されますが、プロモーション期間終了後の金利が高くなる場合があります。借入前には必ず金利や返済条件を確認し、余裕のある返済計画を立てましょう。
