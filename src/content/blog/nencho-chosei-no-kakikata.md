## 年末調整とは？還付金が戻る仕組みを理解しよう

「年末調整って何？」「いくら戻ってくるの？」「住宅ローン控除はどう申請する？」

毎年11月〜12月にかけて、会社から年末調整の書類の記入を求められる方が多いでしょう。しかし、年末調整の仕組みや還付金の計算方法を正しく理解している方は意外と少ないものです。

この記事では、**年末調整の仕組みと還付金の計算**を徹底解説します。年末調整の流れ、還付金が増える控除、扶養親族の申告、住宅ローン控除の申請方法を理解して、還付金を最大化しましょう。

## 年末調整とは

### 年末調整の基本的な仕組み

年末調整とは、**1年間の所得に対する正しい所得税額を計算し、毎月の給料から天引き（源泉徴収）された税額との差額を精算する手続き**です。

源泉徴収は、1年間の収入を予測して概算で所得税を天引きしています。しかし、実際の収入は予測と異なることがあります。また、各種控除を申告することで所得税が減額される場合もあります。年末調整はこのズレを修正する手続きです。

### 還付金が発生する仕組み

源泉徴収税額 > 本来の所得税額 → **還付金が戻る**

源泉徴収税額 < 本来の所得税額 → **追加で納付**

大部分の会社員の場合、各種控除を申告することで還付金が戻ってきます。

## 年末調整の流れ

### 1. 会社から書類の配布（11月頃）

年末調整に必要な書類が会社から配布されます。

| 書類 | 説明 |
|------|------|
| 給与所得者の扶養控除等申告書 | 扶養親族や配偶者の情報を記入 |
| 給与所得者の保険料控除申告書 | 生命保険・社会保険などの控除を申告 |
| 給与所得者の基礎控除申告書 | 基礎控除の申告 |
| 給与所得者の配偶者控除等申告書 | 配偶者控除の申告 |

### 2. 書類の記入と提出（11月〜12月）

配布された書類に必要事項を記入し、会社に提出します。この時に各種控除を正しく申告することが、還付金を増やすカギとなります。

### 3. 会社での計算と調整（12月）

会社が従業員から提出された書類に基づいて、正しい所得税額を計算し、源泉徴収税額との差額を精算します。

### 4. 結果の通知と還付（12月〜1月）

年末調整の結果が給与明細に反映されます。還付金がある場合は、12月または1月の給料に上乗せされて支払われます。

## 還付金が増える主な控除

### 1. 基礎控除

すべての納税者が受けられる控除です。

| 所得金額 | 控除額 |
|---------|--------|
| 2,400万円以下 | 48万円 |
| 2,400万円超〜2,450万円以下 | 32万円 |
| 2,450万円超〜2,500万円以下 | 16万円 |
| 2,500万円超 | 0円 |

### 2. 配偶者控除・配偶者特別控除

配偶者の所得が一定以下の場合に受けられる控除です。

**配偶者控除（配偶者の所得が48万円以下の場合）**

| 配偶者の年齢 | 控除額（納税者の所得900万円以下） |
|-------------|-------------------------------|
| 70歳未満 | 38万円 |
| 70歳以上 | 48万円 |

**配偶者特別控除（配偶者の所得が48万円超〜133万円以下の場合）**

配偶者の所得に応じて段階的に控除額が減ります。配偶者の所得が95万円以下であれば最大38万円の控除が受けられます。

### 3. 扶養控除

扶養親族がいる場合に受けられる控除です。

| 扶養親族の区分 | 控除額 |
|--------------|--------|
| 一般（16歳以上19歳未満） | 38万円 |
| 特定（19歳以上23歳未満） | 63万円 |
| 一般（23歳以上70歳未満） | 38万円 |
| 老人（70歳以上、同居以外） | 48万円 |
| 老人（70歳以上、同居） | 58万円 |

### 4. 生命保険料控除

生命保険の保険料を支払っている場合に受けられる控除です。

**新契約（2012年1月1日以降に締結した契約）**

| 保険の種類 | 年間保険料 | 控除額 |
|-----------|-----------|--------|
| 一般の生命保険 | 2万円以下 | 全額 |
| 一般の生命保険 | 2万円超〜4万円以下 | 2万円＋（保険料−2万円）× 1/2 |
| 一般の生命保険 | 4万円超 | 3万円（上限） |

介護医療保険、個人年金保険も同様にそれぞれ最大3万円の控除があります。

3種類すべての保険に加入している場合、最大で**9万円**の控除が受けられます。

**生命保険料控除による還付金の例：**
- 年間保険料8万円（生命保険4万円＋個人年金4万円）
- 控除額：3万 + 3万 = 6万円
- 還付金（所得税5%+住民税10%）：6万 × 15% = **9,000円**

### 5. 地震保険料控除

地震保険の保険料を支払っている場合に受けられる控除です。

| 年間保険料 | 控除額 |
|-----------|--------|
| 5万円以下 | 支払額 × 1/2 |
| 5万円超 | 2.5万円（上限） |

**地震保険料控除による還付金の例：**
- 年間保険料4万円
- 控除額：4万 × 1/2 = 2万円
- 還付金（所得税5%+住民税10%）：2万 × 15% = **3,000円**

### 6. 社会保険料控除

国民健康保険料、国民年金保険料、介護保険料などの社会保険料を支払っている場合、**支払額の全額**が控除されます（上限なし）。

**社会保険料控除による還付金の例：**
- 年間支払額20万円（国民健康保険料など）
- 控除額：20万円
- 還付金（所得税10%+住民税10%）：20万 × 20% = **40,000円**

社会保険料控除は金額が大きいため、還付金への影響も大きくなります。

## 住宅ローン控除の申請方法

住宅ローン控除は、年末調整で最も大きな還付金をもたらす可能性のある控除です。

### 住宅ローン控除の概要

| 項目 | 内容 |
|------|------|
| 控除額 | 年末残高の1%（最大40万円/年、認定住宅は最大50万円/年） |
| 適用期間 | 最長13年（新築・購入の場合） |
| 対象 | 床面積50㎡以上、居住用の住宅 |
| 収入要件 | 合計所得金額2,000万円以下 |

### 住宅ローン控除の申請手続き

1年目は確定申告が必要ですが、2年目以降は年末調整で申請できます。

**1年目：確定申告**
- 確定申告書に住宅ローン控除の明細書を添付して申告
- 住宅の登記簿謄本、売買契約書などの書類も必要

**2年目以降：年末調整**
- 会社から配布される「住宅借入金等特別控除申告書」に記入
- 金融機関から送付される「住宅取得資金に係る借入金の年末残高等証明書」を添付
- 会社に提出

### 住宅ローン控除による還付金の例

**年末残高3,000万円、所得税率10%の場合**
- 控除額：3,000万 × 1% = 30万円
- 還付金（所得税分）：30万 × 10% = **30万円**

**年末残高2,000万円、所得税率20%の場合**
- 控除額：2,000万 × 1% = 20万円
- 還付金（所得税分）：20万 × 20% = **20万円**

住宅ローン控除は、還付金が数十万円に上る場合もあり、年末調整で最もインパクトの大きい控除です。

## 扶養親族の申告方法

### 扶養親族の条件

扶養控除の対象となる親族は、以下の条件を満たす必要があります。

1. 配偶者以外の親族（6親等内の血族および3親等内の姻族）
2. 納税者と生計を一にしていること
3. 年間の合計所得金額が48万円以下（給与収入のみの場合は103万円以下）
4. 青色申告者の事業専従者として給与を受け取っていないこと
5. 白色申告者の事業専従者でないこと

### 申告に必要な情報

年末調整の申告書に以下の情報を記入します。

- 扶養親族の氏名
- 生年月日
- 続柄
- 同居の有無
- マイナンバー

### 16歳未満の扶養親族

16歳未満の子は扶養控除の対象外ですが、「年少扶養親族」として申告することで、住民税の均等割りが非課税になる場合があります。

## 還付金の計算例

### 年収500万円・独身の場合

| 項目 | 金額 |
|------|------|
| 給与収入 | 500万円 |
| 給与所得控除 | 144万円 |
| 給与所得 | 356万円 |
| 基礎控除 | 48万円 |
| 課税所得 | 308万円 |
| 本来の所得税 | 30.85万円 |
| 源泉徴収税額（概算） | 約33万円 |
| **還付金** | **約2.15万円** |

### 年収500万円・配偶者（専業主婦）＋子供1人（大学生）の場合

| 項目 | 金額 |
|------|------|
| 給与収入 | 500万円 |
| 給与所得控除 | 144万円 |
| 給与所得 | 356万円 |
| 基礎控除 | 48万円 |
| 配偶者控除 | 38万円 |
| 扶養控除（特定） | 63万円 |
| 課税所得 | 207万円 |
| 本来の所得税 | 12.45万円 |
| 源泉徴収税額（概算） | 約33万円 |
| **還付金** | **約20.55万円** |

配偶者控除と扶養控除を申告することで、還付金が約20万円増える例です。正しく申告することの重要性がわかります。

## 年末調整のよくある質問

### 副業がある場合はどうなる？

副業の収入が年間20万円以下であれば、年末調整に含める必要はありません。20万円を超える場合は、確定申告が必要です。年末調整では本業の収入のみを対象とします。

### 複数の会社で働いていた場合は？

年内に転職した場合、前の会社の源泉徴収票を現在の会社に提出すれば、年末調整で通算して精算されます。退職後に年末調整を受けていない場合は、自分で確定申告する必要があります。

### 医療費控除は年末調整で受けられる？

医療費控除は年末調整の対象外です。医療費控除を受けるには、確定申告が必要です。年間10万円以上（または所得の5%以上）の医療費を支払った場合は、確定申告で還付を受けましょう。

## まとめ

- 年末調整は源泉徴収税額と本来の所得税の差額を精算する手続き
- 各種控除を正しく申告することで、還付金を増やすことができる
- 主な控除：基礎控除、配偶者控除、扶養控除、保険料控除、住宅ローン控除
- 住宅ローン控除は最大で年間数十万円の還付があり、インパクトが最も大きい
- 2年目以降の住宅ローン控除は年末調整で申請可能
- 医療費控除など年末調整の対象外の控除は確定申告で申請する

年末調整でいくら戻ってくるか知りたい方は、[年末調整計算器](/nematsu/)でチェックしてみてください。
