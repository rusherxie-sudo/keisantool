## すべてを同じ給与額・同じ割合で計算しない

健康保険と厚生年金は主に標準報酬月額、雇用保険は対象となる実際の賃金を基に計算します。健康保険料率は加入先・都道府県等で違い、年齢によって介護保険も加わります。

## 2026年度の被用者保険の主な項目

| 項目 | 基礎とする金額 | 本人負担の考え方 |
|---|---|---|
| 健康保険 | 健康保険の標準報酬月額 | 協会けんぽでは支部料率の半分 |
| 厚生年金 | 厚生年金の標準報酬月額 | 18.3％の半分＝9.15％ |
| 介護保険 | 健康保険の標準報酬月額 | 協会けんぽの40〜64歳は1.62％の半分 |
| 子ども・子育て支援金 | 健康保険の標準報酬月額 | 2026年4月分から0.23％の半分 |
| 雇用保険 | 対象賃金 | 一般の事業は2026年度0.5％。業種により異なる |

雇用保険料を会社と単純に折半することはできません。労災保険料は全額事業主負担で、本人の給与から控除するものではありません。

## 標準報酬月額には異なる上限がある

給与等を区分表に当てはめた金額が標準報酬月額です。健康保険と厚生年金では等級の範囲が異なるため、特に低額・高額の給与で同じ標準報酬を使うと誤ります。

定時決定では原則4〜6月の報酬等を用いますが、資格取得時の決定、随時改定、休業等の例外があります。現在の給与を表に当てはめた結果と、会社が届け出ている標準報酬月額は常に同じとは限りません。

## 月額30万円の仮定例

健康保険・厚生年金の標準報酬月額がともに30万円、対象賃金も30万円、40歳未満、一般の事業とします。健康保険は全国平均9.90％を仮置きします。

| 項目 | 本人負担の概算 |
|---|---:|
| 健康保険 | 14,850円 |
| 厚生年金 | 27,450円 |
| 子ども・子育て支援金 | 345円 |
| 雇用保険 | 1,500円 |
| 合計 | 44,145円 |

40〜64歳なら、この条件では介護保険2,430円が加わります。全国平均料率は個別の支部料率ではありません。給与控除時の端数処理等も勤務先に確認してください。

## 明細と違う場合の照合順

1. 何月分の保険料を何月の給与から控除しているか。
2. 加入する保険者・支部と、その月の料率。
3. 届出済みの標準報酬月額、年齢と介護保険の対象。
4. 雇用保険の対象賃金と業種。
5. 賞与、休業免除、遡及訂正などの有無。

[社会保険料計算器](/shakaihoken/)は全国平均料率等による概算です。賞与の確認は[ボーナス手取り計算器](/bonus-tedori/)の対応条件をご覧ください。
