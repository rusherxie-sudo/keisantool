給与明細の振込額が前月と違うときは、支給額と控除額のどちらが動いたかを分けて確認すると原因を追いやすくなります。手取りは「支給合計−控除合計」ですが、健康保険・所得税・住民税は同じ金額を基準に計算するわけではありません。

## 最初に勤怠と支給を照合する

雇用契約の基本給、対象期間、勤務日数、残業時間、有給休暇、欠勤控除を並べます。残業代は「時間数」と「割増賃金の基礎となる時給」の両方を確認してください。固定残業代がある場合は対象時間・金額と超過分の扱いも確認します。

通勤手当は一定条件で所得税が非課税でも、社会保険の報酬に含まれる場合があります。課税支給額と支給合計が違っていても、それだけで誤りとはいえません。

## 控除欄で確認する資料

| 明細の項目 | 照合する資料・条件 |
| --- | --- |
| 健康保険・厚生年金 | 勤務先が通知する標準報酬月額、加入支部・組合の料率 |
| 介護保険 | 健康保険と併せて徴収するのは40〜64歳。65歳以降は原則別払い |
| 子ども・子育て支援金 | 2026年4月分から。明細の表示方法・徴収月は勤務先に確認 |
| 雇用保険 | 対象賃金と業種別の本人負担率。会社と同額ではない |
| 所得税 | その月の源泉徴収表、扶養等の申告内容 |
| 住民税 | 自治体の特別徴収税額通知書。通常は前年所得が基礎 |

## 合計を確認するための仮の明細

ここでは税額・保険料を推定する例ではなく、明細に書かれた値を足し引きする練習として示します。

- 支給：基本給250,000円＋残業代30,000円＋通勤手当5,000円＋住宅手当10,000円＝295,000円
- 控除：明細記載の社会保険44,000円＋所得税5,000円＋住民税12,000円＝61,000円
- 差引支給：295,000円−61,000円＝234,000円

この仮定なら振込額234,000円と照合します。現物支給・立替精算・複数口座振込などがある場合は、その項目も含めて確認します。

## 金額が変わったときの質問メモ

「保険料が高い」だけでなく、前月と今月の対象期間、標準報酬月額、適用料率、徴収対象月を給与担当に伝えます。住民税は6月の切替、社会保険は等級改定、年末付近は年末調整による還付・追加徴収も確認候補です。反映月は会社の支払日によって違います。

概算と比較するなら[社会保険料計算](/shakaihoken/)、年間平均の負担なら[給与・手取り計算](/kyuyo/)が使えます。これらの試算と実際の源泉徴収額が一致するとは限りません。
