## 医療費控除でいくら戻る？計算方法と確定申告の手順

一年間で医療費がたくさんかかった…そんな時に役立つのが**医療費控除** です。

「でもいくら戻るの？」「どうやって申告するの？」と迷う方も多いでしょう。

この記事では、医療費控除でいくら戻るのか、計算方法や確定申告の手順をわかりやすく解説します。

### 医療費控除とは？

医療費控除は、**一年間に払った医療費が一定額を超えた場合、所得から控除されて税金が安くなる制度** です。

年末調整では申告できないので、**確定申告** で自分で申告する必要があります。

## 医療費控除の計算方法

### 基本の計算式

```
医療費控除額 ＝ 医療費の合計 − 保険金等の補填額 − 10万円
※ただし最高200万円まで
```

### 10万円の壁

医療費の合計が10万円を超えないと、控除の対象になりません。

- **年間医療費が10万円以下**：控除なし
- **年間医療費が10万円超**：超えた分が控除対象

※所得が200万円以下の方は、10万円ではなく「所得の5%」が基準になります。

### 計算例

#### ケース1：年収400万円、医療費20万円の場合

- 所得税率：10%
- 医療費控除額 ＝ 20万 − 0 − 10万 ＝ 10万円
- 還付額（所得税） ＝ 10万 × 10% ＝ 10,000円
- 還付額（住民税） ＝ 10万 × 10% ＝ 10,000円
- **合計還付額：約20,000円**

#### ケース2：年収600万円、医療費30万円の場合

- 所得税率：20%
- 医療費控除額 ＝ 30万 − 0 − 10万 ＝ 20万円
- 還付額（所得税） ＝ 20万 × 20% ＝ 40,000円
- 還付額（住民税） ＝ 20万 × 10% ＝ 20,000円
- **合計還付額：約60,000円**

#### ケース3：出産で医療費50万円かかった場合

- 所得税率：10%
- 医療費控除額 ＝ 50万 − 42万（出産育児一時金） − 10万 ＝ 0円

出産育児一時金（42万円）が補填されるので、実際には控除対象にならないケースが多いです。ただし、出産育児一時金を差し引いても10万円を超える場合は控除の対象になります。

## 医療費控除の対象になる費用

医療費控除の対象になる主な費用は以下の通りです。

### 対象になるもの

| 費用 | 備考 |
|------|------|
| 病院の診察費・治療費 | 歯科治療も含む |
| 処方箋の薬代 | 薬局での支払い |
| 市販薬（セルフメディケーション税制の対象） | 一定の条件あり |
| 入院費用 | 部屋代差額は対象外 |
| 治療用器具の購入費 | 松葉杖・コルセットなど |
| 通院交通費 | 電車・バス・タクシー代 |
| 親族の医療費 | 生計を一にする親族分 |
| 出産費用 | 正常な分娩も対象 |
| 介護保険サービスの自己負担分 | 一定の条件あり |

### 対象にならないもの

| 費用 | 理由 |
|------|------|
| 美容整形（自由診療） | 治療目的ではない |
| 健康診断の費用 | 予防的処置 |
| 入院時の個室差額ベッド代 | 治療に直接関係しない |
| サプリメント代 | 治療に直接関係しない |
| 歯科矯正（美容目的） | 治療目的ではない |

### 通院交通費も対象！

電車・バス・タクシーでの通院交通費も医療費控除の対象です。ガソリン代や駐車場代は対象外ですが、公共交通機関の費用は忘れずに計上しましょう。

## 家族の医療費も合算できる

医療費控除は、**生計を一にする家族の医療費を合算** して申告できます。

例えば：
- 自分の医療費：8万円
- 配偶者の医療費：5万円
- 子供の医療費：3万円
- **合計：16万円 → 10万円を超えるので控除対象**

誰の所得から控除するかは選べます。**所得税率が一番高い人（一番所得が多い人）** の所得から控除するのがお得です。

## 確定申告の手順

### 必要なもの

- 源泉徴収票（会社員の場合）
- 医療費の領収書
- マイナンバー
- 還付金を受け取る口座情報

### 手続きの流れ

#### 1. 医療費の領収書を集める

一年間の医療費の領収書をすべて集めます。なくした場合は、病院に再発行を依頼できます。

#### 2. 医療費控除の明細書を作成する

医療費の日付・病院名・金額・誰の医療費かをまとめます。e-Taxの画面上で入力できます。

#### 3. 確定申告書を作成する

e-Tax（オンライン申告）で確定申告書を作成します。医療費控除の欄に合計額を入力します。

#### 4. 確定申告書を提出する

e-Taxで提出するか、税務署に持参・郵送します。

#### 5. 還付金が振り込まれる

申告後、1〜2ヶ月で指定した口座に還付金が振り込まれます。

### 5年間さかのぼって申告できる

過去に医療費控除を申告し忘れた場合、**5年前までさかのぼって** 確定申告できます。還付金も受け取れます。

## セルフメディケーション税制との違い

医療費控除には、「一般の医療費控除」と「セルフメディケーション税制」の2種類があります。

| 項目 | 一般の医療費控除 | セルフメディケーション税制 |
|------|-----------------|---------------------------|
| 対象 | すべての医療費 | 対象市販薬のみ |
| 控除の基準 | 10万円超 | 12,000円超 |
| 控除上限 | 200万円 | 88,000円 |
| 条件 | なし | 健康の保持増進のための取組を行っていること |

セルフメディケーション税制は市販薬を買った人向けの制度で、控除額が少ない代わりに基準が低いです。どちらか有利な方を選択できます。

## まとめ

- 医療費控除は一年間の医療費が10万円を超えた分が控除対象
- 還付額は「医療費控除額 × 所得税率」
- 家族の医療費は合算できる
- 年末調整ではなく確定申告で申告する
- 5年前までさかのぼって申告可能

医療費控除を申告すれば、数千円〜数万円の還付が受けられます。年間医療費が10万円を超えそうな方は、領収書を保管しておきましょう。
